Vue Composables

useFilters()

Singleton — shared filter state across all views. Watches reset on navigation.
Returns
  • selectedPeriodref
  • selectedLocationref
  • selectedCategoryref
  • selectedStatusref
  • hasActiveFilterscomputed
  • getCurrentFilters()method
  • resetFilters()method

useAuth()

Mock auth — always authenticated. User name/role switches with locale.
Returns
  • currentUsercomputed locale-aware
  • isAuthenticatedref always true
  • logout()method alert only
  • getInitials(name)method

useI18n()

Two locales: en / ja. Persisted to localStorage. Currency follows locale (USD / JPY).
Returns
  • t(key, params)method dot notation + fallback
  • setLocale(locale)method
  • currentLocalecomputed
  • currentCurrencycomputed USD / JPY
  • translateProductName()method
  • translateWarehouse()method
